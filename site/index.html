Built for the way you work

Close the session.
Keep the thread.

You work on a side project, a client repo, and a dozen things that have nothing to do with code. The next step is easy to lose between them.

MontyBrain gives each project a home. Topics hold the context. Tasks hold the next steps. A journal records what happened, so you and your agent can start the next session with the same picture.

01 / Get it out of your head

Capture now.
Sort it out later.

A global shortcut opens quick capture over your current app. Type a task, add !high or @tomorrow if you like, and get back to what you were doing.

The inbox keeps loose ends together until you are ready to move them into a project or topic.

of things to do.

Keep the summary, repository, tasks, and journal together inside a topic. A board shows progress. A dependency map helps you follow what is waiting on what.

Open Today for deadlines, work in progress, blockers, and recent updates across your projects.

Prefer to build from source?

You need macOS, Xcode Command Line Tools, Rust 1.89+, Node.js 22.12+, and pnpm 10.

Get the source
git clone --depth 1 https://github.com/bartlomiejmont/montybrain.git montybrain
cd montybrain

The Git clone command will appear here once the public repository is announced. From an existing source checkout, run:

Build the app · from the source directory
pnpm install --frozen-lockfile
pnpm tauri build --bundles app
open target/release/bundle/macos/MontyBrain.app

For the MCP server and agent skills, run ./install.sh from the source checkout. It builds the server and registers it with installed Claude Code and Codex CLIs. Start a new agent session afterward.

A shallow clone skips old commits. For later source updates, run git pull --ff-only, install dependencies again, and rebuild. Run ./install.sh again to update MCP and the skills.

A few useful details

Before you
get started.

Is MontyBrain free?

Yes. MontyBrain is open source under the MIT license. You can use, modify, and redistribute it. Claude Code and Codex are separate products; their subscriptions or API usage are not included.

Does it work offline?

The desktop app stores and manages tasks locally. You do not need a MontyBrain account or cloud connection. Agent features use your installed CLI and may send task content and repository context to that provider.

Is the app in English?

Yes. The interface defaults to English, with Polish available in Settings → App language. Commands accept English words such as !high and @tomorrow. The Markdown files keep Polish section names and status values, as shown in the file example above.

What about Windows, Linux, or team sync?

The desktop app currently targets macOS. There are no Windows or Linux desktop builds, built-in cross-device sync, or multi-user collaboration. The standalone MCP server can be built separately from the desktop app.

Can I edit the Markdown files myself?

Yes. The app watches the vault and reloads external changes. The app and MCP server coordinate their writes, but your text editor does not use that lock. Avoid saving the same file from your editor while an agent or the app is writing to it, and keep backups.

Why are downloads hosted on GitHub?

GitHub Releases keeps application packages separate from the source history and the landing page. You download directly from GitHub. Developers can use a shallow Git clone to get just the latest source snapshot and build locally.
